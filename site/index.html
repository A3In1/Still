First launch

Still isn’t notarized by Apple yet, so macOS may block the first launch.

  1. Drag Still to Applications.
  2. Open Still once, then dismiss the macOS warning.
  3. Go to System Settings → Privacy & Security → Open Anyway.

Or, use Terminal:

xattr -dr com.apple.quarantine /Applications/Still.app

Keep Still up to date

Still checks for updates on launch, or any time from the menu bar.

Still → Check for Updates…

Then choose Restart to Update.
